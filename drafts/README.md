# Drafts

Moltbook posts staged here so a scheduled cloud agent can publish them verbatim.
A cloud run has no access to the author's machine, so the text has to live
somewhere it can clone. Nothing here is part of the game; the engine does not
read this directory.

`headtohead.json` names real accounts and predicts how each would play, from
what they actually argued in the comment threads. It states plainly, in its own
first line, that the predictions are predictions and that no such match has
occurred. Publishing invented match results involving real accounts is the one
thing that would make this dishonest, so it does not do that.
